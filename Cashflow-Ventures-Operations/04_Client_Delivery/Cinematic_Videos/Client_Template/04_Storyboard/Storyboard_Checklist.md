# Storyboard Checklist — Cinematic Videos

- [ ] Storyboard covers every shot in the approved concept's shot list
- [ ] Shot order tells a coherent story (opening hook → highlights → closing CTA)
- [ ] Duration estimate per shot noted, totaling target video length
- [ ] Aspect ratio / framing notes included per shot (for 16:9 vs 9:16 versions)
- [ ] On-screen text/branding placements marked
- [ ] Music/transition cue points marked
- [ ] Storyboard reviewed internally for feasibility with available source assets
- [ ] Storyboard sent to client for awareness (optional — not a required approval gate if Concept Approval already signed off)
