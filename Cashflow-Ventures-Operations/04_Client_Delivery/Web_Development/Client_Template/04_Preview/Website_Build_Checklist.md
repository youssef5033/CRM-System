# Website Build Checklist

Complete before sending the client a preview link.

## Setup

- [ ] Project started from standardized `05_Assets/Website_Templates` base
- [ ] Domain/staging URL confirmed for preview

## Pages

- [ ] Home page built with hero, key services, CTA
- [ ] About page built
- [ ] Services page built
- [ ] Gallery / Reviews page built with client's supplied reviews
- [ ] Contact page built with form + map + hours

## Functionality

- [ ] Click-to-call phone number active on mobile
- [ ] Click-to-WhatsApp button active (if applicable)
- [ ] Contact form tested — submissions arrive by email
- [ ] Google Map embedded with correct pin
- [ ] Business hours and address correct on every page

## Branding & Content

- [ ] Logo placed in header/footer
- [ ] Brand colors and fonts applied
- [ ] All client-supplied copy placed (or drafted copy inserted for approval)
- [ ] All client-supplied images placed and optimized

## Technical

- [ ] Mobile-responsive check (phone, tablet, desktop)
- [ ] Page load speed check
- [ ] Page titles and meta descriptions set for each page
- [ ] Image alt text added
- [ ] Google Analytics tracking code installed
- [ ] No broken links or placeholder text remaining

## Ready for Preview

- [ ] Preview link works and loads correctly in an incognito window
- [ ] Preview link sent to client
- [ ] Master CRM updated: Preview Status → "Sent"
- [ ] Client Record checklist updated: "04_Preview delivered" checked
