# Cinematic Videos — Proposal Checklist

Use before sending any cinematic video proposal.

## Before drafting

- [ ] Lead exists in Master CRM (`01_Master_CRM`) with a Lead ID
- [ ] Pipeline Stage is at least "Qualified" or a preview has been sent
- [ ] Preview (cinematic concept clip or before/after) reviewed with client, or scheduled
- [ ] Confirmed decision-maker / contact who can approve and pay
- [ ] Confirmed which assets the client can supply (photos, video, floorplans, brand)

## Drafting the proposal

- [ ] Copy `Cinematic_Video_Proposal_Template.md` into `02_Proposals/Cinematic_Videos/Drafts/`
- [ ] Rename to `PROP-{ID}_Cinematic-Videos_{Business-Name}_{YYYY-MM-DD}.md`
- [ ] Fill in every `{{PLACEHOLDER}}` — no unresolved placeholders remain
- [ ] Confirm number of deliverables, durations, and aspect ratios
- [ ] Confirm usage rights section matches client's intended use
- [ ] Set Expiry Date (recommend proposal date + 7–14 days)
- [ ] Set target Delivery Date for final unwatermarked files
- [ ] Proofread for client name, property name, and pricing accuracy

## Sending

- [ ] Move file from `Drafts/` to `Sent/`
- [ ] Update Master CRM: Pipeline Stage → "Proposal Sent"
- [ ] Log an Activity in the Activities tab (Activity Type: "Proposal Sent")
- [ ] Set Next Action + Next Action Date (e.g., "Follow up on proposal" in 3 business days)

## After response

- [ ] **If accepted:** move file to `Accepted/`, update Pipeline Stage → "Verbal Yes" or "Deposit Invoiced", create the client delivery folder in `04_Client_Delivery/Cinematic_Videos/Active/`, issue the deposit invoice from `03_Payments`
- [ ] **If rejected/no response after expiry:** move file to `Rejected/`, update Pipeline Stage → "Lost" or "Nurture", record Lost Reason in Master CRM

## Reminder

Final, unwatermarked exports are never released before the final payment is confirmed as "Paid" in the Payment Tracker.
