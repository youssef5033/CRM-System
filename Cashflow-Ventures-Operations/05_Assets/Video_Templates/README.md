# Video Templates

Store reusable cinematic video building blocks here — the assets referenced during `04_Client_Delivery/Cinematic_Videos/Client_Template/03_Concept_and_Script` and `04_Storyboard` work:

- Branded intro/outro templates (logo stinger, end card with contact info/CTA)
- Lower-third / text overlay templates
- Licensed or royalty-free music tracks by mood (aspirational, energetic, luxury, family-friendly)
- Editing/AI-generation project presets by property type (residential listing, commercial, golf/country club, campus, rental)

As you complete real client projects, save a genericized/portfolio-safe copy of strong deliverables here for reuse and for showing prospects examples of your work (only where usage rights allow it — see each client's `09_Usage_Rights` record).
