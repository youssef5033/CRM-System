# Website Templates

Store the standardized base template(s) used to start every Web Development project here — the theme/starter files referenced by `04_Client_Delivery/Web_Development/Client_Template/04_Preview/Website_Build_Checklist.md` ("Project started from standardized `05_Assets/Website_Templates` base").

Keep at least:

- One default 5-page local-service-business template (Home, About, Services, Gallery/Reviews, Contact)
- Any vertical-specific variants (e.g., dental, home services, restaurants)
- A short README noting which template version is "current" for new projects

As you complete real client projects, save a genericized/portfolio-safe copy of strong builds here for reuse and for showing prospects examples of your work.
