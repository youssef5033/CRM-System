# Outreach Templates

Store reusable cold-outreach and follow-up message templates here, for logging as Activities in the Master CRM:

- Cold email templates (per venture, and per vertical if you specialize outreach)
- Follow-up email sequence templates
- WhatsApp / Instagram DM opening message templates
- LinkedIn connection + follow-up message templates

Suggested naming: `{Venture}_{ActivityType}_{Variant}.md`, e.g. `Cinematic-Videos_Cold-Email_Realtors.md`. Keep these short and easy to personalize — they should map to the **Activity Type** dropdown values used in the Master CRM's Activities tab (Cold Email, Follow-Up Email, WhatsApp, LinkedIn, Instagram DM, etc.).
